# 控制系统
目标：定位四台电机转速不一致的原因。

## 基准与结论

- **控制-K1**：原接法下四台电机转速不同。同侧两台共用一路遥控 PWM，各有一只 Favourite Sleeping Lion 120A 电调，原因待实测。
- **控制-K2**：动力电池为 6S、标称 22.2 V。电机商品规格为 C6374、170 KV、有感，实装标签待核对。
- **控制-K3**：ESP32 正式版已烧录并确认上电锁定，精简版已通过编译。整车架空验证待做。
- **控制-K4**：精简版 `SIMPLE-0.2` 已改为逐脉冲转发，同侧共用一个硬件 PWM 输出。编译通过，待烧录并按控制-T1、控制-T3 核对稳态轮速和电调输入波形。
- **控制-K5**：2026-11-18 用户报告正式版 `FW 0.4.0` 无法通过推杆解锁，四台电机均未转动，遥控驱动验收失败。详见[控制系统 README 的控制-K84](控制系统/README.md#基准与结论)。
- **控制-K6**：当前系统为开环油门控制，无转速闭环反馈。换装 ESP32 本身不会自动消除转速差，须先排除硬件与机械差异，再视需要通过四路独立参数微调。
- **控制-K7**：2026-11-24 现场核实：缓慢推油门时四电机依次起转、稳态转速各不相同；直连接收机与接入 ESP32 现象一致，排除 ESP32 为主因；断电手转四轮阻力均匀无卡点，基本排除机械卡滞主因；四只电调从未统一校准油门行程或读写参数。现有工具含万用表、USB 调参线，可用主机 SSH 另一台接 ESP32 的电脑远程控制串口。第一怀疑对象锁定为四只电调行程或内部参数不一致。

以下为基于开环架构的可能原因（推测，待实测定位），按排查优先级排序：

| 优先级 | 可能原因 | 机理 | 典型表现 | 对应排查 |
| --- | --- | --- | --- | --- |
| 1 | 四只电调行程或参数不一致 | 中位、端点、启动功率、进角独立保存，低油门段放大明显 | 同侧两轮不同步、起步晚 | 控制-T4、T7 |
| 2 | 机械阻力或装配差异 | 开环下转速对负载敏感，轴承偏紧、啮合紧或刮蹭拉低转速 | 低油门差距大、高油门缩小，手转手感不均 | 控制-T2 |
| 3 | 遥控左右通道信号差异 | 已实测 CH2 与 CH4 存在 3–6 µs 偏差，见控制系统 README 控制-K77，叠加微调或回中误差 | 左两轮一致、右两轮一致，仅左右两侧有差 | 控制-T3 |
| 4 | 有感霍尔接触不良或异常 | C6374 有感电机霍尔虚接可能降级为无感或换相偏移 | 伴随低速抖动、异响、顿挫或发热 | 控制-T5 |
| 5 | 供电链路压降不均 | 6S 分线长度、焊点或插头接触电阻差异导致大电流时母线压降不同 | 空载差别小，四路同转或带载加速时掉速 | 控制-T6 |
| 6 | 电机 KV 个体公差 | 磁钢与绕组出厂离散，通常在 3%–8% 内 | 空载全速段呈小幅固定比例差异，无卡滞或抖动 | 控制-T8 |

快速定位顺序：

1. 架空低油门观察分组形态：左右成组有差查控制-T3，同侧两轮不一致则排除遥控信号，聚焦电调、机械与霍尔。
2. 断电手转四轮，快速排查机械卡滞与阻力不均，见控制-T2。
3. 断电仅互换同侧两只电调：慢速随电调走则锁定电调参数或校准问题，留在原轮位则查机械、霍尔或电机，见控制-T7。

接线和固件详见[控制系统资料](控制系统/README.md)。排查依据见 [FVT 实物拆解](https://kaspars.net/blog/fvt-firmware)、[BLHeli 参数手册](https://github.com/bitdump/BLHeli/blob/master/SiLabs/BLHeli%20manual%20SiLabs%20Rev14.x.pdf)、[TI 换相说明](https://www.ti.com/document-viewer/lit/html/SLAAE95A/GUID-46F248D2-1B32-4D5F-82E0-D1509641BB4F)、[Fluke 压降测量](https://www.fluke.com/en-us/learn/blog/automotive/electrical-automotive-troubleshooting)。
