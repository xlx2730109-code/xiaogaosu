#### 原模型各要素与命令

来源 `adams_export/m_out_cmd.cmd`。

| 要素 | 命令 |
|---|---|
| 导入几何 | `file parasolid read file_name= model_name=` |
| 重力 | `force create body gravitational` |
| 转动副 | `constraint create joint revolute`，`i_marker_name`、`j_marker_name` |
| 移动副 | `constraint create joint translational` |
| 固定副 | `constraint create joint fixed` |
| 驱动 | `constraint create motion_generator`，`type_of_freedom`、`joint_name`、`function` |
| 接触 | `contact create type=solid_to_solid`，`i_geometry_name`、`j_geometry_name`、`stiffness`、`damping`、`exponent`、`dmax`、`mu_static`、`mu_dynamic` |
| 仿真 | `simulation single_run transient end_time= step_size=` |

- **K23**：91 个零件的几何来自同一个 Parasolid 文件，每个实体各属一个零件，零件名为默认名（`PART3`、`NONE_66` 等）；推测原作者导入了 SolidWorks 装配体的 Parasolid。
- **K24**：91 个零件密度均为 2700 kg/m³，质量由几何体积算出，不是实测质量；需与 `../1_重量评估.xlsx` 对照。
- **K25**：铰链全部由 marker 对定义，marker 的位置与方向记录在 `adams_export/m_out.adm`，复现时可直接取用。
- **K26**：接触参数为刚度 1e8 N/m、阻尼 1e4 N·s/m（刚度的 0.01%）、指数 2.2、穿透深度 0.1 mm，与资料中硬质材料的常用值一致。
- **K27**：命令文件中没有积分器设置，推测原仿真使用默认求解器设置，未验证。

#### 资料要点

- **K28**：从 SolidWorks 到 Adams 推荐用 Parasolid（`.x_t`）；STEP 可能导入为单个实体，且无法选取孔、销等特征定位铰链。
- **K29**：Parasolid 不带约束，铰链、驱动、接触都要在 Adams 中重建。
- **K30**：转动副需要两个重合且平行的 marker。
- **K31**：接触为 `F = k·x^e`，阻尼随穿透深度升到最大值；常用指数 2.2、穿透深度 0.1 mm；最大阻尼取刚度的 0.01%–1%，各资料不一致。
- **K32**：批处理命令为 `adams2024_1 aview ru-s b <脚本>`，脚本可为 `.cmd` 或 Python（`adamspy`）；在 `.cmd` 中运行 Python 用 `var set var= int = (eval(run_python_code("exec(open('<路径>').read())")))`。
- **K33**：仿真前需先复位（reset），再设时长与步长。

### D. 阶梯赛道极限测试

目标：做一条逐级加难的连续赛道，让样机一路爬，停在哪一级，哪一级就是极限；斜坡与台阶各做一条，先按默认参数完成，再逐项优化。
